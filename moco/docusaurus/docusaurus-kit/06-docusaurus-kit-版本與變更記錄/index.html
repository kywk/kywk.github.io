docusaurus-kit 版本與變更記錄

這篇只記錄 docusaurus-kit 套件與 repository 本身的版本和里程碑。

目前版本​

套件npm latest說明
docusaurus-theme-pele0.1.2Pele Mermaid renderer
docusaurus-plugin-album0.1.1Pinterest 瀑布流相簿、Google Photos 時間軸與全螢幕燈箱
remark-obsidian-kanban0.3.1Obsidian Kanban → 靜態看板

版本紀錄​

docusaurus-theme-pele​

版本日期變更
0.1.02026-10-20首發。Pele renderer、CSS 變數主題、themeConfig.pele.zoom、fixture/Playwright 測試
0.1.12026-10-20補充 Docusaurus / React / Node.js / Pele 相容版本說明
0.1.22026-10-23當瀏覽器暫時性網路錯誤導致 Pele chunk 載入失敗時，允許後續重試載入

docusaurus-plugin-album​

版本日期變更
0.1.02026-10-23首次以 npm 套件發佈。包裝 @docusaurus/plugin-content-blog，提供 Pinterest 瀑布流、Google Photos 時間軸滑桿、沉浸式 Hero Header、零依賴燈箱與首頁輕量 albumItems JSON 分塊
0.1.12026-10-23新增 tsconfig.theme.json 將 lib/theme/ 元件預先編譯為 ESM JavaScript，解決消費端站台從 node_modules 載入時的 bundler 轉譯問題（同時保留 src/theme/*.tsx 供 swizzle 使用）

remark-obsidian-kanban​

版本日期變更
0.2.02026-10-20首次以 npm 套件發佈。可選 pageResolver / hrefTemplate、狀態 class、settings 區塊移除、5 個單元測試
0.2.12026-10-20補充相容版本說明
0.3.02026-10-21卡片標題與內文的 #tag 轉成藥丸標籤（顏色由名稱雜湊決定），站台隨即切換為 npm 版本
0.3.12026-10-23優化 AST 走訪效能，並將重複的看板卡片 inline style 移至看板共用樣式表

rehype-obsidian-tasks​

版本日期變更
0.2.02026-10-20首次以 npm 套件發佈。[-] / [/]、GFM 相容、loose list 處理、4 個單元測試
0.2.12026-10-20補充相容版本說明
0.2.22026-10-23優化 AST 走訪效能

npm 首次發佈時可能出現短暫的 0.0.0-stage 版本，那是 staged publish 的佔位版本；在瀏覽器完成同意後會 promote 成正式版本。

發佈方式​

套件使用 Changesets 管理版本；push 到 main 後由 Release workflow 開 version PR，合併後以 OIDC 發佈。完整流程見 04 GitHub Actions 與 npm 信任發佈。
