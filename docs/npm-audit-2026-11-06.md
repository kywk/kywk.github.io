# npm 相依套件安全稽核（2026-11-06）

## 範圍與結果

以網站目前的 `package-lock.json`、Node 22.23.3，以及 npm registry 當日回應進行 `npm audit --json`。原報告的 55 是**受影響的套件項目**，不是 55 個不同弱點：其中 31 個套件有自身通報，依 GitHub advisory URL 去重後共 114 個公告（5 critical、49 high、44 moderate、16 low）；npm 分別列出不同版本範圍時共有 117 筆來源紀錄，其餘項目是沿依賴鏈傳播的嚴重度。這些數字會隨 registry 更新而改變。

修補後的完整稽核與 `--omit=dev` 均回報 0 critical、0 high、0 moderate、5 low；5 個項目都是單一 `deepmerge` advisory 沿 SVGR 和 Docusaurus 依賴鏈傳播，不是 5 個獨立漏洞。`npm audit` 仍會因此以非零狀態結束。

## 影響判斷

網站部署至 GitHub Pages 的是靜態檔，並未在 Pages 上提供 Docusaurus 的 Node 開發伺服器；伺服器套件的網路漏洞不能直接等同於公開網站上的 Node 端點。但 build 及開發工具會處理內容與設定，若引入不可信的 PR、圖片或設定，仍須評估建置、CI 機密及本機開發環境；未證明可利用不等於不可能利用。

| 主要接觸處 | 原始有自身通報的套件 | 風險與處置 |
| --- | --- | --- |
| 建置、解析與素材 | `ajv`、`brace-expansion`、`colord`、`fast-uri`、`image-size`、`joi`、`js-yaml`、`lodash`、`picomatch`、`postcss-selector-parser`、`serialize-javascript`、`source-map-js`、`svgo`、`tinypool`、`webpack` | 惡意內容、設定或程式物件可能導致建置阻斷、原型污染或程式碼執行；修補對應版本。 |
| 本機開發／代理伺服器 | `body-parser`、`compression`、`http-proxy-middleware`、`launch-editor`、`node-forge`、`path-to-regexp`、`proxy-addr`、`qs`、`shell-quote`、`uuid`、`webpack-dev-server`、`websocket-driver`、`ws` | 實際風險依監聽介面、使用的 API、代理設定及不可信輸入而定；修補對應版本。 |
| 建置或工具的網路請求 | `follow-redirects`、`undici` | 特定重導向、TLS、快取或回應處理情境可能洩漏資料或拒絕服務；修補對應版本。 |
| 尚未修補的建置依賴 | `deepmerge` | 單一 low advisory；見下方剩餘風險。 |

例如，Docusaurus 啟用 SSG worker，確實會使用 Tinypool；但其 RCE advisory 的利用需要先具備原型污染等前提，未證明本站存在該輸入路徑。`proxy-addr` 的 IP 偽造則需要受影響的信任代理子網設定，本站未發現明設該設定。詳見 [Tinypool advisory](https://github.com/advisories/GHSA-85c8-ppgw-ccpr) 與 [proxy-addr advisory](https://github.com/advisories/GHSA-jqcg-44mw-7w3h)。

## 套用的修補

- 在既有依賴版本範圍內更新鎖檔，包含 `image-size`、`js-yaml`、`fast-uri`、Express 與 WebSocket 相關修補；未使用 `npm audit fix --force` 或降版 Docusaurus。
- 對尚未擴大版本範圍的上游套件，僅在指定父依賴下固定安全版本：`@docusaurus/core` → `tinypool@2.1.2`、`copy-webpack-plugin` 與 `css-minimizer-webpack-plugin` → `serialize-javascript@7.1.3`、`sockjs` → `uuid@11.1.1`。
- 這些覆寫跨越上游宣告的主版本範圍，並非上游相容性保證。Tinypool 是建置時實際使用的 worker；Copy/CSS 插件在本站 Rspack 預設路徑並非主要實例，但仍限制各自的覆寫；SockJS 僅呼叫 UUID v4，該 UUID advisory 所列為帶外部 buffer 的 v3/v5/v6。修補仍需維持下列測試，並在上游支援修補版本後移除不再需要的覆寫。

## 剩餘風險

`@docusaurus/preset-classic` → `@docusaurus/plugin-svgr` → `@svgr/webpack` → `@svgr/plugin-svgo` → `deepmerge@4.3.1` 仍被 [GHSA-gcqx-w48m-w2h4](https://github.com/advisories/GHSA-gcqx-w48m-w2h4) 標示：合併不可信來源物件時，回傳物件的原型可能遭污染。公告目前沒有修補版本；不為清零而降至較舊、未經驗證的版本。檢查所安裝的 `@svgr/plugin-svgo@8.1.0` 執行入口，未看到它直接匯入 `deepmerge`；一次合成 SVG 最佳化測試也未載入該套件，但這不能證明所有執行路徑皆不可達。應追蹤上游修補，並持續審查不可信 SVG 與建置設定。

## 本次驗證

- 隔離目錄執行 `npm ci --engine-strict`、`npm ls`、`npm run typecheck`、`npm run content:check`，以及雙 SSG worker 的正式建置；內容檢查有 0 error、62 個既有 warning。
- 修補前後正式建置均有 2,716 個 `index.html` 路徑，沒有增減；瀏覽器驗證旅程索引、StoryMap、Relive 播放與 24 張照片的 3D 彈窗。
- Tinypool 新舊版本以同一合成 worker 測試 500 個併發任務、例外傳遞、低門檻回收及 destroy；另用 webpack 合成測試實際經過 Copy transform/cache、CSS 平行 worker、JS/CSS 與 source map。
- 本機 SockJS WebSocket 實際連線與訊息往返，以及隔離 Docusaurus 開發伺服器的熱更新均通過。
- Linux x64 容器使用 Node 22.23.3、Git、嚴格引擎檢查及兩個 SSG worker，乾淨安裝、依賴樹、型別／內容檢查與正式建置均通過；本機 Docker 因記憶體限制而限制 CPU／heap，環境不等同 GitHub runner。
- 候選版相簿曾出現一次 chunk 載入錯誤；修補前後各重試兩次，以及候選版 10 次全新載入與站內往返均未重現。原因尚未確認；額外相簿冒煙測試封鎖外部網路，未驗證 Flickr 圖片。
- 這些本機測試不等於 GitHub Actions 已執行本次未提交變更，也不等於已部署。
