# spring 2012

二〇一二年的春風拂過島嶼東岸，將日子梳理得舒緩而明亮。從宜蘭員山水塘邊現烤香魚的裊裊熱氣，到清晨奔跑在玉里田間產業道路時撲面而來的青草微風；眼前是滿片新綠稻田與連綿遠山，腳下是踏實節奏。那些沒有刻意編排的日常與行腳，在微涼春光中被鏡頭安靜收攏，凝結成那一季最溫潤的生活切片。
