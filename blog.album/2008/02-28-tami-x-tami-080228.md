# Tami x Tami (08.02.28)

二月底初春微涼的午後，光線穿透林梢與街角縫隙，在快門輕巧落下的瞬間悄悄沉澱。鏡頭前是靈動而真實的神態，在雙重映照的視角裡，定格了毫無矯飾的純粹與自在。那一天的微風、流轉的笑意與安靜對話的片刻，就這樣被溫柔收進光影切片之中，任歲月靜靜發酵，留下最真實溫暖的模樣。
