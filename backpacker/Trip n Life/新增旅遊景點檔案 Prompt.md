新增與更新旅遊景點檔案 Prompt
========================================

使用專案的 `travel-attraction-writing` skill，產生以行前規劃為主、保留個人心得的景點介紹。支援單一景點與城鎮／區域介紹；多日行程另行安排。

## 快速使用

在此 Git 專案的 Codex 對話中，貼上以下指令並替換方括號內容。目標路徑建議寫完整路徑，避免從不同工作目錄執行時存錯位置。

### 新增單一景點

```text
$travel-attraction-writing

請介紹「[中文名稱／當地名或英文名]」，位於「[國家／地區]」。
將文章新增至「[目標目錄完整路徑]」。

以行前規劃為主，自動查詢可靠來源，依景點特色安排內容。
保留「我的心得」區塊；沒有我提供的素材就留白。
```

### 批次新增景點或城鎮

```text
$travel-attraction-writing

請在「[目標目錄完整路徑]」為以下地點各建立一篇介紹：
- [地點一，所屬地區]
- [地點二，所屬地區]
- [地點三，所屬地區]

先檢查是否已有相同地點的筆記，已有者更新原檔。
依介紹範圍選擇單一景點或城鎮／區域模組。
完成後列出新增、更新的檔案及影響出行的待確認資訊。
```

### 更新既有文章

```text
$travel-attraction-writing

請更新「[文章完整路徑]」。
查核交通、開放時間、費用與預約資訊，補齊有助行前規劃的內容。
保留既有 frontmatter、連結與「我的心得」原文，採局部修改。
若尚無「我的心得」，補上空白區塊。
```

## 可補充的旅行條件

有確定資料時再加到指令中；未提供的日期、出發點或個人經驗不由 agent 推測。

```text
預計旅遊日期：[年月或日期範圍]
出發點：[城市／住宿地點]
交通偏好：[大眾運輸／自駕／其他]
可用時間與需求：[例如半日、少階梯、攝影、歷史背景]

我的心得素材：
[貼上實際觀察或感受；可請 agent 整理新增素材。
若要改寫既有心得，另外明確說明「請潤飾既有心得」。]
```

## 預期文章內容

先提供位置、適合對象、建議停留、季節與時段、開放、費用及預約的速覽，再介紹看點與背景、交通、遊覽安排及注意事項。城鎮／區域文補充分區與串遊順序；餐廳可改用特色、菜色及訂位資訊。

每篇固定保留「我的心得」，並附資料來源與查核日期。背景深度依景點調整，不硬湊字數或填滿所有選用段落。

檢查成品時，特別確認：

- 中外文名稱、位置與入口指向同一地點；座標須有可靠依據，未知時省略，不為了讓標記分散而調整座標。
- 票價、班次、開放與預約資訊註明來源、查核日及適用條件；無法確認時明確標示。
- 既有個人心得保留原文，網站作者的體驗不寫成我的親身經歷。
- 內部連結指向已存在的筆記；沒有相關連結時省略 `See Also`。
