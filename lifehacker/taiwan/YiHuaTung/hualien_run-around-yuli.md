# Run around Yuli

![玉里](http://farm8.staticflickr.com/7102/7017034143_b7542b950a_o.png)

  

  

早在去老房子之前，就想過該跑跑步保持運動。  

透過 google map 規劃了路線，共 10.5km 路線簡單、起伏緩和，很理想的路徑。  

  

  
[檢視較大的地圖](http://maps.google.com.tw/maps?f=d&source=embed&saddr=%E5%92%8C%E5%B9%B3%E8%B7%AF&daddr=23.333751,121.313983+to:23.335282,121.312068+to:23.3041361,121.2939368+to:%E5%92%8C%E5%B9%B3%E8%B7%AF&hl=zh-TW&geocode=FWEEZAEdOx07Bw%3BFXcLZAEdvxo7Bym74bEJfGpvNDEbOhHwKP0Bsg%3BFXIRZAEdRBM7Bym97nGDfmpvNDEymvhojjRKrw%3BFciXYwEdcMw6BynLt1dH4mpvNDEbxrAlUsT46Q%3BFRwEZAEdUB07Bw&sll=23.331871,121.315802&sspn=0.00865,0.009452&t=m&brcurrent=3,0x346f42bc59e818c7:0x61997179dab2508b,0,0x346fb8d2a52a0401:0xcf6871e475b3f2ff&mra=dme&mrsp=4&sz=17&via=1,2,3&ie=UTF8&ll=23.328819,121.3164&spn=0.013792,0.018239&z=15)  

以老房子為起終點，沿著和平路往北跑，左轉民族路，左轉西邊街，直行續接水源路、源城產業道路，遇土地公廟後左轉接上台30線，沿台30進玉里市區，左轉中山路，繞圓環回和平路。  

  

![玉里](http://farm8.staticflickr.com/7059/6870927260_7e52a31193_z.jpg)

  

  

整條路徑視野廣闊，風景明媚。滿片稻田配上遠山，很漂亮的路徑！  

  

但除了源城產業道路有些樹蔭外，全無遮蔽物，若陽光太烈會很辛苦。  

而台30線車輛多且急，後半段改行環鎮自行車道或田間的產業道路會更好。  

  

綜合來說，這是條很舒服的跑步路線，下回還要再去跑一趟。
